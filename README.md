## Overview

This project is a RESTful API for managing a library book collection, built using **Node.js** and **Express.js**. The records are maintained entirely in an in-memory JavaScript array without any external database (MongoDB/MySQL).

## Setup & Run Instructions

### 1. Prerequisites
Ensure you have **Node.js** (v18+) and **npm** installed on your system.

### 2. Install Dependencies
Open your terminal in the project directory and run:
```bash
npm install
```

### 3. Start the Server
Start the Express server on port `3000`:
```bash
npm start
```
*Alternatively, run:*
```bash
node server.js
```

You should see the startup message:

With the server running (or in a separate terminal), run:
```bash
npm test
```

## Record Structure

Each book record contains the following fields:

| Field | Data Type | Description |
|---|---|---|
| `id` | Number | Unique numeric identifier generated by the application |
| `title` | String | Title of the book |
| `author` | String | Name of the author |
| `genre` | String | Book category or genre |
| `publishedYear` | Number | Year of publication |
| `available` | Boolean | Availability status of the book |

## API Endpoints

### 1. Get All Books
- **Method:** `GET`
- **Route:** `/api/books`
- **Response Status:** `200 OK`
- **Description:** Returns all book records in JSON format.

---

### 2. Filter Books by Author
- **Method:** `GET`
- **Route:** `/api/books/filter?author=<value>`
- **Response Status:** `200 OK`
- **Description:** Filters books matching the author name using case-insensitive matching. Returns an empty array `[]` if no matching book is found.
- **Example:** `GET /api/books/filter?author=paulo`

---

### 3. Get Book by ID
- **Method:** `GET`
- **Route:** `/api/books/:id`
- **Response Status:** `200 OK` (if found) / `404 Not Found` (if not found)
- **Description:** Returns the book matching the given numeric `id`.
- **Example:** `GET /api/books/101`

---

### 4. Create New Book
- **Method:** `POST`
- **Route:** `/api/books`
- **Headers:** `Content-Type: application/json`
- **Response Status:** `201 Created` / `400 Bad Request` (validation failure)
- **Sample Request Body:**
```json
{
  "title": "The Discovery of India",
  "author": "Jawaharlal Nehru",
  "genre": "History",
  "publishedYear": 1946,
  "available": true
}
```

---

### 5. Update Book by ID
- **Method:** `PUT`
- **Route:** `/api/books/:id`
- **Headers:** `Content-Type: application/json`
- **Response Status:** `200 OK` / `404 Not Found` / `400 Bad Request`
- **Sample Request Body:**
```json
{
  "title": "The Alchemist – Revised Edition",
  "author": "Paulo Coelho",
  "genre": "Fiction",
  "publishedYear": 1988,
  "available": true
}
```

---

### 6. Delete Book by ID
- **Method:** `DELETE`
- **Route:** `/api/books/:id`
- **Response Status:** `200 OK` / `404 Not Found`
- **Description:** Deletes the record with the given ID and returns a success confirmation message.
- **Example:** `DELETE /api/books/103`

## Testing with Postman / Thunder Client / cURL

### cURL Examples

```bash
# 1. Get all books
curl -X GET http://localhost:3000/api/books

# 2. Filter by author (case-insensitive)
curl -X GET "http://localhost:3000/api/books/filter?author=paulo"

# 3. Get book by ID
curl -X GET http://localhost:3000/api/books/101

# 4. Create a new book
curl -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  -d "{\"title\":\"The Discovery of India\",\"author\":\"Jawaharlal Nehru\",\"genre\":\"History\",\"publishedYear\":1946,\"available\":true}"

# 5. Update book
curl -X PUT http://localhost:3000/api/books/102 \
  -H "Content-Type: application/json" \
  -d "{\"title\":\"The Alchemist – Revised Edition\",\"author\":\"Paulo Coelho\",\"genre\":\"Fiction\",\"publishedYear\":1988,\"available\":true}"

# 6. Delete book
curl -X DELETE http://localhost:3000/api/books/103
```
